# 💻 LeetCode Solutions

Welcome to my **LeetCode Solutions** repository!

This repository contains my solutions to LeetCode problems solved as part of my Data Structures and Algorithms (DSA) practice. The repository is automatically maintained using **LeetHub**, which synchronizes accepted LeetCode submissions directly to GitHub.

## 🎯 Objective

- Strengthen Data Structures & Algorithms concepts
- Improve problem-solving skills
- Prepare for coding interviews
- Track learning progress
- Build consistency through regular practice

- ✅ Each accepted problem is stored in its own folder
- ✅ Includes the original problem statement

- ✅ Covers Easy, Medium, and Hard problems
